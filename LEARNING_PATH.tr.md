# SQL Server Course Labs — Türkçe Öğrenme Yolu

**[English](LEARNING_PATH.md) | Türkçe** · [Türkçe README](README.tr.md)

Bu çalışma yolu, mevcut SQL betiklerinin sırasını ve hedeflerini Türkçe açıklar. **SQL dosyaları iki dilde ortaktır**; sorgu adları ve komutları çevrilmez.

## Ön hazırlık

Yalıtılmış bir Microsoft SQL Server test ortamı ve bir T-SQL istemcisi hazırla. `DROP`, veri yükleme, trigger ve veri değiştiren komutları üretim veritabanında çalıştırma.
