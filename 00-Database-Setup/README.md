# 00 — Database Setup

This module prepares the practice environment used across all labs.

## Objectives
- Create and initialize the BikeStores sample database.
- Create a lightweight UniversityDB for academic query scenarios.
- Reset and reload objects/data when needed.

## Scripts
- `BikeStores Sample Database - create objects.sql`: creates BikeStores schema objects.
- `BikeStores Sample Database - load data.sql`: loads seed/sample data.
- `BikeStores Sample Database - drop all objects.sql`: cleanup/reset script.
- `Create-UniversityDB.sql`: creates UniversityDB and core tables.
- `University-Queries.sql`: starter analytical queries for UniversityDB.

## Suggested Run Order
1. Create objects
2. Load data
3. Validate with sample queries
4. Use drop script only for clean reset
